우리 반 AI 자료 확인 체크리스트

예시

모둠의 확인 포인트를 교사가 다듬어 전자칠판에 함께 보여 줍니다. 수업 중 채워질 결과의 예시입니다.

  1. 1
    주장 단위로 쪼개고 출처 찾아보기

    답변을 주장 단위로 쪼개 확인하고, AI가 댄 출처를 직접 찾아 열어 본다.

  2. 2
    출처가 주장을 뒷받침하는지 확인하기

    출처가 주장을 정말 뒷받침하는지, 숫자와 표현이 같은지 확인한다.

  3. 3
    검색으로 교차 확인하기

    검색으로 교차 확인하고 비판적으로 받아들인다.

  4. 4
    원래 맥락과 원 출처까지 추적하기

    원래의 맥락과 원 출처까지 추적해 본다.

  5. 5
    숫자가 무엇을 센 것인지 확인하기

    숫자가 무엇을 센 것인지(범위·정의·조건)와 몇 년 자료인지 확인한다.

  6. 6
    출처가 있어도 내용이 바뀔 수 있다

    출처가 실제로 있어도 AI가 숫자나 내용을 바꿔 쓸 수 있고, 존재하지 않는 인용을 만들어 낼 수도 있음을 인지한다.

우리가 찾은 확인 포인트로, 다음 차시에 내가 모아 온 자료를 검증해 봐요.

종이 활동지 대신 웹으로 설계한 이유: AI와의 대화가 웹과 모바일에서 이루어지므로, 학생이 웹페이지와 PDF를 직접 열어 읽고 정리하게 했습니다.

성취기준과 학습 목표

[12주탐01-04] 주제와 관련된 책이나 자료를 탐색하면서 신뢰할 수 있고 가치 있는 정보를 선정하여 분석하며 읽는다.

  1. 1모둠원과 자료를 나누어 맡아 자료카드와 원문을 직접 조사한다.
  2. 2조사 결과를 모아 비교하고 판정 4단계로 말하며 근거를 한 문장으로 쓴다.
  3. 3모둠이 찾은 확인 포인트를 공유해 ‘우리 반 AI자료 확인 체크리스트’를 만든다.
  4. 4체크리스트로 처음 판단을 다시 살펴보고, 앞으로 확인할 내용을 자신의 말로 정리한다.

교사가 조사해 정리한 확인 기준 5가지

AI 자료를 쓸 때 어떤 기준으로 검증해야 하는지에 대한 명확한 가이드라인이 없어, 여러 자료를 조사해 정리했습니다.

  1. 1답변을 주장 단위로 쪼개 확인하고, AI가 댄 출처를 직접 찾아 열어 본다.
  2. 2출처가 주장을 정말 뒷받침하는지, 숫자와 표현이 같은지 확인한다.
  3. 3검색으로 교차 확인하고 비판적으로 받아들인다.
  4. 4원래의 맥락과 원 출처까지 추적해 본다.
  5. 5출처가 실제로 있어도 AI가 숫자나 내용을 바꿔 쓸 수 있고, 존재하지 않는 인용을 만들어 낼 수도 있음을 인지한다.

학생들이 실제로 만드는 체크리스트는 다른 형태일 수 있으나, 대동소이할 것으로 예상합니다.

수업자의 고민

1/4 · 왜 이 수업인가
  • 학생들의 모습

    학생들은 개인별 탐구 주제를 정하고 자료를 모으고 있습니다. 그런데 AI가 준 답변이나 인터넷 자료는 ‘근거 자료가 붙어 있고 숫자가 구체적이면 맞다’고 받아들이기 쉽습니다.

  • 이 수업의 자리

    자료를 활용하기 전 단계입니다. 가상 학생 ‘지현’이 AI에게 받은 답변을 함께 조사하며, AI 자료를 쓸 때 무엇을 확인해야 하는지 스스로 발견하는 연습입니다.

  • 한 차시의 한계

    학생이 직접 검증 자료를 찾는 과정은 한 차시에 하기 어렵다고 판단했습니다. 이번 차시는 교사가 설정한 흐름 안에서 ‘AI 자료는 이런 기준으로 검증한 뒤 쓴다’를 인지하는 단계이고, 다음 차시부터 2~3차시에 걸쳐 자신이 받은 자료를 실제로 검증합니다.

수업자의 고민

2/4 · 수업 구성의 의도
  • 기준을 먼저 알려 주지 않기

    기준을 알려 주고 적용시키는 대신 ‘조사 → 발견 → 공유 → 체크리스트 만들기’ 순서로 설계했습니다.

  • 개인 → 모둠 → 전체

    5개 모둠이 문장을 하나씩 맡아 조사하고, 모둠의 확인 포인트를 모아 ‘우리 반 AI 자료 확인 체크리스트’를 완성합니다. 모둠 정리는 다수결이 아니라 근거 비교로 합의하고, 기록자 한 명이 입력합니다.

  • 4단계 판정

    확인됨 / 부분적으로 맞음 / 확인 불가 / 사실 아님은 조사 결과를 말하는 도구입니다. ‘틀렸다’, ‘확인할 수 없다’, ‘맞지만 설명이 부족하다’는 서로 다른 판정이라는 점을 다룹니다.

수업자의 고민

3/4 · 설계하며 고민한 점
  • 교사의 기준은 참고용

    AI 자료를 어떤 기준으로 검증해야 하는지 명확한 가이드라인이 없어, 여러 자료를 조사해 5가지로 정리했습니다. 이는 교사가 정리한 것일 뿐, 학생들이 만드는 체크리스트는 다른 형태일 수 있습니다. 대동소이할 것으로 예상합니다.

  • 종이 활동지와 웹 사이에서

    종이 활동지를 쓰는 방안도 고민했습니다. 하지만 AI와의 대화가 웹이나 모바일에서 이루어지므로, 웹페이지나 PDF를 실제로 열어 읽고 정리하는 과정을 거치도록 설계했습니다. 그래서 전용 웹앱, 교사 화면, 전자칠판 무대 화면을 바이브코딩으로 직접 만들었습니다.

수업자의 고민

4/4 · 아쉬움
  • 가장 아쉬운 점

    수업 설계를 위해 조사한 자료 대부분이 영어 웹페이지라, 학생들이 번역한 글을 읽으며 내용을 파악해야 합니다. 지현의 보고서 주제를 ‘fast fashion’으로 정할 때 예측했으면 좋았겠지만, 이미 많이 진행된 뒤에 깨달아 돌이키기에는 시간이 부족했습니다. 수업에서는 번역 방법과 광고 없이 읽는 ‘읽기모드’를 안내합니다.

AI의 답은 탐구의 출발점이지 인용할 결론이 아닙니다. 우리가 찾은 확인 포인트로 검증한 뒤에 씁니다.
